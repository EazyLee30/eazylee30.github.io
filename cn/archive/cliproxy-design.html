◆ 第一部分：用印尼 GoPay 免费搞到 ChatGPT Plus

OpenAI 在部分地区推出了 0 元试用 Plus 的活动，配合印尼的电子钱包 GoPay 可以零成本完成订阅。核心思路：注册一个新的 ChatGPT 账号 → 触发 0 元试用 → 用 GoPay 作为支付方式（实际不扣钱）→ 订阅成功后立即取消自动续费。

1. 准备工作与账号注册

  • 准备一个邮箱，建议专门注册新小号，干净利落
  • 下载 WhatsApp 和 GoPay（印尼电子钱包），去 Google Play 或外网应用市场下载
  • 用你的 +86 国内手机号注册 WhatsApp 和 GoPay，直接登录即可

2. 注册 ChatGPT 账号

  • 把梯子切到日本节点（或其他支持的地区）
  • 用准备好的邮箱注册一个全新的 ChatGPT 账号
  • 登录后进入 ChatGPT 主页

3. 获取 0 元试用

  • 在页面顶部找「升级 Plus」点进去，或留意左下角的优惠提示
  • 目标是找到 「0 元试用」 的入口
  • 到订阅页面后，右下角把地区手动切换成 印度尼西亚
  • 支付方式选 GoPay

4. 填写账单地址

  • 网上搜一个「新加坡地址生成器」，随便生成一个虚拟地址
  • 把地址填到账单信息里

5. 配置 GoPay 支付密码

  • 打开手机上的 GoPay App
  • 点右下角 Profil（个人资料）
  • 找到带 PIN 字样的设置项，输入两次支付密码，确认

6. 完成订阅

  • 回到 ChatGPT 订阅页面点订阅
  • 填手机号时选 +86 (China)，填国内手机号
  • 验证码不会走短信，会发到 WhatsApp 上，进去收验证码填上
  • 订阅完成！

7. 立即取消自动续费（关键！）

这一步必须做！否则免费期过了会自动扣钱。
  • 回到 ChatGPT 页面，左下角 → 设置 → 账户 → 管理
  • 进去把订阅取消掉
  • 这样免费期结束后就不会扣费，而 Plus 权限在试用期内照常使用
多注册几个账号，每个都走一遍这个流程，就得到了一个 Plus 账号池。后面用 CLIProxyAPI 统一管理。

◆ 第二部分：搭建 CLIProxyAPI 多账号代理

CLIProxyAPI 是一个用 Go 写的代理服务器，可以把多个 ChatGPT/Claude/Gemini 账号聚合成标准的 OpenAI 兼容 API。支持轮询负载均衡、额度耗尽自动切换、会话亲和等特性。

CLIProxyAPI Web 管理面板登录页

1. 安装 CLIProxyAPI

macOS 用 Homebrew 安装（需要先添加 tap）：

brew tap tianyicui/homebrew-cliproxyapi
brew install cliproxyapi

或者直接下载预编译二进制：

# macOS ARM (Apple Silicon)
curl -L -o cliproxy.tar.gz \
  "https://github.com/router-for-me/CLIProxyAPI/releases/download/v6.10.8/CLIProxyAPI_6.10.8_darwin_aarch64.tar.gz"
tar -xzf cliproxy.tar.gz
sudo cp cli-proxy-api /usr/local/bin/

Linux 一键安装脚本：

curl -fsSL https://raw.githubusercontent.com/router-for-me/cliproxyapi-installer/refs/heads/master/cliproxyapi-installer | bash

2. 登录 ChatGPT 账号

对每个 Plus 账号执行一次 OAuth 登录：

cli-proxy-api -config ~/.cli-proxy-api/config.yaml -codex-login

浏览器会自动打开 OpenAI 授权页面，登录后凭证自动保存到 ~/.cli-proxy-api/ 目录。有几个号就跑几次。

3. 配置文件

编辑 ~/.cli-proxy-api/config.yaml：

host: ""
port: 8317

remote-management:
  allow-remote: false
  secret-key: "你的管理面板密码"

auth-dir: "~/.cli-proxy-api"

api-keys:
  - "你的API密钥"  # 用 openssl rand -hex 32 生成

request-retry: 3

quota-exceeded:
  switch-project: true       # 额度用完自动换号
  switch-preview-model: true  # 自动切换到预览模型

routing:
  strategy: "round-robin"    # 轮询分配请求

4. 启动服务

# 后台启动
nohup cli-proxy-api -config ~/.cli-proxy-api/config.yaml > /tmp/cli-proxy-api.log 2>&1 &

# 或者用 TUI 模式（交互式终端界面）
cli-proxy-api -config ~/.cli-proxy-api/config.yaml -tui

5. 验证 API

# 查看可用模型
curl http://localhost:8317/v1/models \
  -H "Authorization: Bearer 你的API密钥"

# 测试对话
curl http://localhost:8317/v1/chat/completions \
  -H "Authorization: Bearer 你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.5","messages":[{"role":"user","content":"hello"}]}'

6. 管理面板

浏览器打开 http://localhost:8317/management.html，用配置的管理密码登录，可以看到所有账号状态、模型列表、请求统计等。

◆ 第三部分：接入 Open Design 实现 AI 设计

Open Design 是 Anthropic Claude Design 的开源替代品。完全本地运行、Web 可部署、全 BYOK 架构。它不自带 AI agent——而是复用你机器上已有的 coding agent CLI（Claude Code、Codex、Cursor、Gemini CLI 等 15 种），把它们变成设计引擎。

Open Design — 开源 Claude Design 替代品

核心设计理念

Open Design 有六个核心设计哲学：

  • 不自带 agent — 扫描 PATH 上的 15+ CLI 工具，每个都能当设计引擎
  • 技能即文件 — 遵循 Claude Code 的 SKILL.md 规范，放个文件夹、重启就能用
  • 设计系统是 Markdown — 不是 JSON 主题文件，而是 9 段式 DESIGN.md（颜色、排版、间距、布局、组件、动效、语调、品牌、反模式）
  • 交互式需求表单 — 编码前先问清楚，减少 80% 的返工
  • 本地守护进程 — agent 真正读写你本地文件系统，会话持久化到 SQLite
  • Prompt 栈即产品 — 由发现指令 + 身份宪章 + 设计系统 + 技能定义 + 项目元数据组合而成

◆ 第四部分：高级玩法与成本分析

账号池策略

注册多个 Plus 账号（建议 3-5 个），每个都通过 GoPay 0 元试用获得 Plus 权限。CLIProxyAPI 会自动轮询：

  • 正常情况下 round-robin 均匀分配请求
  • 某个账号额度耗尽 → 自动跳过，切换到下一个
  • 支持 session-affinity，同一会话绑定同一账号
  • OAuth token 自动刷新，无需手动维护
