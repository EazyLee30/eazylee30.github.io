◆ Part 1: Free ChatGPT Plus via Indonesian GoPay

OpenAI offers a free Plus trial in certain regions. Combined with GoPay (an Indonesian e-wallet), you can subscribe at zero cost. The flow: register a new ChatGPT account → trigger the free trial → use GoPay as payment (no actual charge) → immediately cancel auto-renewal.

1. Preparation

  • Prepare a fresh email (dedicated account recommended)
  • Download WhatsApp and GoPay from Google Play or other app stores
  • Register both with your +86 phone number

2. Register ChatGPT Account

  • Switch your VPN to a Japan node (or other supported region)
  • Register a new ChatGPT account with your prepared email

3. Get the Free Trial

  • Click "Upgrade to Plus" at the top, or look for a promotional prompt
  • Find the "Free trial" entry point
  • On the subscription page, switch region to Indonesia
  • Select GoPay as payment method

4. Billing Address

  • Search for a "Singapore address generator" online
  • Fill in a generated virtual address

5. Set Up GoPay PIN

  • Open the GoPay app on your phone
  • Tap Profil (bottom right)
  • Find the PIN setting, enter your payment PIN twice, confirm

6. Complete Subscription

  • Return to the ChatGPT subscription page and click Subscribe
  • Select +86 (China) for phone verification, enter your number
  • The verification code arrives on WhatsApp, not SMS — check WhatsApp and enter the code
  • Subscription complete!

7. Cancel Auto-Renewal Immediately (Critical!)

Do this NOW or you'll be charged when the trial ends.
  • Go to ChatGPT → Settings → Account → Manage
  • Cancel the subscription
  • You keep Plus access during the trial period, but won't be charged after
Repeat for multiple accounts to build a Plus account pool. CLIProxyAPI will manage them all.

◆ Part 2: CLIProxyAPI Multi-Account Proxy

CLIProxyAPI is a Go proxy server that aggregates multiple ChatGPT/Claude/Gemini accounts into a standard OpenAI-compatible API. Features round-robin load balancing, auto-failover on quota exhaustion, and session affinity.

CLIProxyAPI web management panel login

1. Install CLIProxyAPI

macOS via Homebrew:

brew tap tianyicui/homebrew-cliproxyapi
brew install cliproxyapi

Or download the pre-built binary directly:

# macOS ARM (Apple Silicon)
curl -L -o cliproxy.tar.gz \
  "https://github.com/router-for-me/CLIProxyAPI/releases/download/v6.10.8/CLIProxyAPI_6.10.8_darwin_aarch64.tar.gz"
tar -xzf cliproxy.tar.gz
sudo cp cli-proxy-api /usr/local/bin/

Linux one-liner:

curl -fsSL https://raw.githubusercontent.com/router-for-me/cliproxyapi-installer/refs/heads/master/cliproxyapi-installer | bash

2. Log In ChatGPT Accounts

Run OAuth login for each Plus account:

cli-proxy-api -config ~/.cli-proxy-api/config.yaml -codex-login

A browser window opens for OpenAI authorization. Credentials are saved to ~/.cli-proxy-api/. Repeat for each account.

3. Configuration

Edit ~/.cli-proxy-api/config.yaml:

host: ""
port: 8317

remote-management:
  allow-remote: false
  secret-key: "your-management-password"

auth-dir: "~/.cli-proxy-api"

api-keys:
  - "your-api-key"  # generate with: openssl rand -hex 32

request-retry: 3

quota-exceeded:
  switch-project: true
  switch-preview-model: true

routing:
  strategy: "round-robin"

4. Start the Service

# Background
nohup cli-proxy-api -config ~/.cli-proxy-api/config.yaml > /tmp/cli-proxy-api.log 2>&1 &

# Or TUI mode (interactive terminal UI)
cli-proxy-api -config ~/.cli-proxy-api/config.yaml -tui

5. Verify the API

# List available models
curl http://localhost:8317/v1/models \
  -H "Authorization: Bearer your-api-key"

# Test chat completion
curl http://localhost:8317/v1/chat/completions \
  -H "Authorization: Bearer your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.5","messages":[{"role":"user","content":"hello"}]}'

6. Management Panel

Open http://localhost:8317/management.html in your browser. Log in with your management password to see account status, model lists, and request statistics.

◆ Part 3: Open Design for AI-Powered Design

Open Design is the open-source alternative to Anthropic's Claude Design. Runs locally, web-deployable, fully BYOK. It doesn't ship its own AI agent — instead it reuses the coding agent CLIs already on your machine (Claude Code, Codex, Cursor, Gemini CLI, and 11 others) and turns them into design engines.

Open Design — open-source Claude Design alternative

Core Design Philosophy

Open Design is built on six load-bearing ideas:

  • No bundled agent — scans PATH for 15+ CLIs; each becomes a candidate design engine
  • Skills are files — follows Claude Code's SKILL.md convention; drop a folder, restart daemon
  • Design Systems are Markdown — 9-section DESIGN.md schema (color, typography, spacing, layout, components, motion, voice, brand, anti-patterns)
  • Interactive question form — discovery before coding, prevents 80% of redirects
  • Local daemon — agent gets real filesystem access; sessions persist in SQLite
  • Prompt stack is the product — composed of discovery directives + identity charter + DESIGN.md + SKILL.md + project metadata

1. Install Open Design

git clone https://github.com/nexu-io/open-design.git
cd open-design
corepack enable
pnpm install

Requires Node.js 24+ and pnpm 10.33.x (managed via Corepack).

2. Configure API Proxy

Point Open Design's BYOK endpoint to CLIProxyAPI to use your free GPT account pool:

  • In Open Design settings, configure the OpenAI-compatible endpoint
  • Base URL: http://localhost:8317/v1
  • API Key: the key from your CLIProxyAPI config

All AI calls from Open Design will route through CLIProxyAPI, automatically rotating across your Plus accounts.

3. Launch

# Daemon + web (foreground)
pnpm tools-dev run web

# Daemon + web (background)
pnpm tools-dev start web

# Check status
pnpm tools-dev status

# View logs
pnpm tools-dev logs

# Stop
pnpm tools-dev stop

Open http://localhost:63559 in your browser.

◆ Part 4: Advanced Tips & Cost Analysis

Account Pool Strategy

Register 3-5 Plus accounts, each with the GoPay free trial. CLIProxyAPI handles the rest:

  • Quota exhausted on one → auto-skip to next, transparent to client
  • session-affinity binds sessions to accounts for consistency
  • OAuth tokens auto-refresh — zero maintenance
