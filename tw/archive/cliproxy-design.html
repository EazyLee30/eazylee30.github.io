◆ 第一部分：用印尼 GoPay 免費搞到 ChatGPT Plus

OpenAI 在部分地區推出了 0 元試用 Plus 的活動，配合印尼的電子錢包 GoPay 可以零成本完成訂閱。核心思路：註冊一個新的 ChatGPT 賬號 → 觸發 0 元試用 → 用 GoPay 作為支付方式（實際不扣錢）→ 訂閱成功後立即取消自動續費。

1. 準備工作與賬號註冊

  • 準備一個郵箱，建議專門註冊新小號，乾淨利落
  • 下載 WhatsApp 和 GoPay（印尼電子錢包），去 Google Play 或外網應用市場下載
  • 用你的 +86 國內手機號註冊 WhatsApp 和 GoPay，直接登入即可

2. 註冊 ChatGPT 賬號

  • 把梯子切到日本節點（或其他支援的地區）
  • 用準備好的郵箱註冊一個全新的 ChatGPT 賬號
  • 登入後進入 ChatGPT 主頁

3. 獲取 0 元試用

  • 在頁面頂部找「升級 Plus」點進去，或留意左下角的優惠提示
  • 目標是找到 「0 元試用」 的入口
  • 到訂閱頁面後，右下角把地區手動切換成 印度尼西亞
  • 支付方式選 GoPay

4. 填寫賬單地址

  • 網上搜一個「新加坡地址生成器」，隨便生成一個虛擬地址
  • 把地址填到賬單資訊裡

5. 配置 GoPay 支付密碼

  • 開啟手機上的 GoPay App
  • 點右下角 Profil（個人資料）
  • 找到帶 PIN 字樣的設定項，輸入兩次支付密碼，確認

6. 完成訂閱

  • 回到 ChatGPT 訂閱頁面點訂閱
  • 填手機號時選 +86 (China)，填國內手機號
  • 驗證碼不會走簡訊，會發到 WhatsApp 上，進去收驗證碼填上
  • 訂閱完成！

7. 立即取消自動續費（關鍵！）

這一步必須做！否則免費期過了會自動扣錢。
  • 回到 ChatGPT 頁面，左下角 → 設定 → 賬戶 → 管理
  • 進去把訂閱取消掉
  • 這樣免費期結束後就不會扣費，而 Plus 許可權在試用期內照常使用
多註冊幾個賬號，每個都走一遍這個流程，就得到了一個 Plus 賬號池。後面用 CLIProxyAPI 統一管理。

◆ 第二部分：搭建 CLIProxyAPI 多賬號代理

CLIProxyAPI 是一個用 Go 寫的代理伺服器，可以把多個 ChatGPT/Claude/Gemini 賬號聚合成標準的 OpenAI 相容 API。支援輪詢負載均衡、額度耗盡自動切換、會話親和等特性。

CLIProxyAPI Web 管理面板登入頁

1. 安裝 CLIProxyAPI

macOS 用 Homebrew 安裝（需要先新增 tap）：

brew tap tianyicui/homebrew-cliproxyapi
brew install cliproxyapi

或者直接下載預編譯二進位制：

# macOS ARM (Apple Silicon)
curl -L -o cliproxy.tar.gz \
  "https://github.com/router-for-me/CLIProxyAPI/releases/download/v6.10.8/CLIProxyAPI_6.10.8_darwin_aarch64.tar.gz"
tar -xzf cliproxy.tar.gz
sudo cp cli-proxy-api /usr/local/bin/

Linux 一鍵安裝指令碼：

curl -fsSL https://raw.githubusercontent.com/router-for-me/cliproxyapi-installer/refs/heads/master/cliproxyapi-installer | bash

2. 登入 ChatGPT 賬號

對每個 Plus 賬號執行一次 OAuth 登入：

cli-proxy-api -config ~/.cli-proxy-api/config.yaml -codex-login

瀏覽器會自動開啟 OpenAI 授權頁面，登入後憑證自動儲存到 ~/.cli-proxy-api/ 目錄。有幾個號就跑幾次。

3. 配置檔案

編輯 ~/.cli-proxy-api/config.yaml：

host: ""
port: 8317

remote-management:
  allow-remote: false
  secret-key: "你的管理面板密码"

auth-dir: "~/.cli-proxy-api"

api-keys:
  - "你的API密钥"  # 用 openssl rand -hex 32 生成

request-retry: 3

quota-exceeded:
  switch-project: true       # 额度用完自动换号
  switch-preview-model: true  # 自动切换到预览模型

routing:
  strategy: "round-robin"    # 轮询分配请求

4. 啟動服務

# 后台启动
nohup cli-proxy-api -config ~/.cli-proxy-api/config.yaml > /tmp/cli-proxy-api.log 2>&1 &

# 或者用 TUI 模式（交互式终端界面）
cli-proxy-api -config ~/.cli-proxy-api/config.yaml -tui

5. 驗證 API

# 查看可用模型
curl http://localhost:8317/v1/models \
  -H "Authorization: Bearer 你的API密钥"

# 测试对话
curl http://localhost:8317/v1/chat/completions \
  -H "Authorization: Bearer 你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.5","messages":[{"role":"user","content":"hello"}]}'

6. 管理面板

瀏覽器開啟 http://localhost:8317/management.html，用配置的管理密碼登入，可以看到所有賬號狀態、模型列表、請求統計等。

◆ 第三部分：接入 Open Design 實現 AI 設計

Open Design 是 Anthropic Claude Design 的開源替代品。完全本地執行、Web 可部署、全 BYOK 架構。它不自帶 AI agent——而是複用你機器上已有的 coding agent CLI（Claude Code、Codex、Cursor、Gemini CLI 等 15 種），把它們變成設計引擎。

Open Design — 開源 Claude Design 替代品

核心設計理念

Open Design 有六個核心設計哲學：

  • 不自帶 agent — 掃描 PATH 上的 15+ CLI 工具，每個都能當設計引擎
  • 技能即檔案 — 遵循 Claude Code 的 SKILL.md 規範，放個資料夾、重啟就能用
  • 設計系統是 Markdown — 不是 JSON 主題檔案，而是 9 段式 DESIGN.md（顏色、排版、間距、佈局、元件、動效、語調、品牌、反模式）
  • 互動式需求表單 — 編碼前先問清楚，減少 80% 的返工
  • 本地守護程序 — agent 真正讀寫你本地檔案系統，會話持久化到 SQLite
  • Prompt 棧即產品 — 由發現指令 + 身份憲章 + 設計系統 + 技能定義 + 專案後設資料組合而成

◆ 第四部分：高階玩法與成本分析

賬號池策略

註冊多個 Plus 賬號（建議 3-5 個），每個都透過 GoPay 0 元試用獲得 Plus 許可權。CLIProxyAPI 會自動輪詢：

  • 正常情況下 round-robin 均勻分配請求
  • 某個賬號額度耗盡 → 自動跳過，切換到下一個
  • 支援 session-affinity，同一會話繫結同一賬號
  • OAuth token 自動重新整理，無需手動維護
