Three locally authored SVG covers illustrate functions documented by the
repositories, rather than imitating application screenshots:

- prompt-gallery.svg: prompt browsing, output previews and copying, from
  [gpt-image2-gallery](https://github.com/EazyLee30/gpt-image2-gallery).
- edcbook-caster.svg: computer-to-e-ink casting and touch control, from
  [edcbook-caster](https://github.com/EazyLee30/edcbook-caster).
- location-voting.svg: GPS radius verification for local voting, from
  [location-voting-app](https://github.com/EazyLee30/location-voting-app).

The EDCBook Caster card links to the actual demonstration listed in its README.
XFXCode's public repository distributes releases and documentation; its card
labels the repository as GitHub rather than presenting it as application source.
